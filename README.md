# Desafio — Teste de Ludo

Partida simplificada para dois jogadores, com quatro peças por jogador. A suíte cobre
saída da base com seis, movimentação, troca/manutenção de turno, captura, chegada e
encerramento.

```bash
npm test
```

## Especificação e casos de teste

O modelo considera dois jogadores, cada um com quatro peças. Uma peça sai da base
apenas ao tirar seis; a suíte também verifica movimento, troca de turno, captura,
chegada ao final e término da partida.
